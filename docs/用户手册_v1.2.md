# LiuScope（柳镜）用户手册 · v1.2 新功能篇

适用版本 v1.2.x。基础收发与波形用法见 [README](../README.md)；AI 通道完整协议见 [AI_INTERFACE.md](../AI_INTERFACE.md)。
本手册只讲 v1.2 新增/重构的功能：设置页与主题、终端页新交互、波形页读数与导出、频谱导出口径、STM32 烧录页、AI 控制通道速用。

---

## 0. 快速上手（exe 用户，5 分钟）

1. 从 [Releases](https://github.com/TZH-user/liuscope/releases) 下载 `liuscope.exe` 与 `SHA256SUMS.txt`。
2. 校验（可选但推荐）：`certutil -hashfile liuscope.exe SHA256`，与 SHA256SUMS.txt 比对。
3. 双击运行。首次启动 SmartScreen 提示时点「更多信息 → 仍要运行」；杀软误报时校验哈希后加白名单。
4. 插入串口设备 → 终端页选 COM 口与波特率 → 连接。

**配置与数据**：配置在 `gui_settings_qt.ini`（与 exe 同目录），日志在 `logs\`（勾选「自动保存日志」后生成）。升级直接覆盖 exe，配置向前兼容；重置 = 删除该 ini。
**卸载**：删除 `liuscope.exe` + `gui_settings_qt.ini` + `logs\` 即可，不写注册表、无残留。

**故障排查**：

| 现象 | 处置 |
|---|---|
| 双击无反应 / 报缺 DLL | 安装 VC++ 运行库；看 `logs\` 与弹窗信息 |
| 首次启动慢（3~10 秒） | onefile 单文件自解压特性，非卡死 |
| 找不到 COM 口 | 装 CH340/CP210x 驱动；设备管理器确认 |
| 串口被占用 | 关闭其他占用程序（含另一个 LiuScope 实例） |
| STM32 页探测不到 ST-LINK | 设置页确认 CLI 路径；装 STM32CubeProgrammer 与 ST-LINK 驱动 |

## 1. 设置页与主题

入口：页签 **设置**。

- **主题**：深色 / 浅色 二选一下拉，切换立即生效（含所有页签、绘图区、右键菜单），重启后保持。
  - 已知限制：终端页**已落显的历史日志行**保留切换当时的配色，新行按新主题着色；点「清空记录」即可整体刷新。
- **曲线填充**：勾选后波形曲线下方填充半透明色。原波形页内的复选框已迁移至此，全局生效。
- **STM32 CLI 路径**：STM32CubeProgrammer 命令行完整路径。**留空 = 自动探测**（按 `X:\ST\STM32CubeProgrammer\bin\STM32_Programmer_CLI.exe` 模式扫描各盘符 + PATH）。装在非标准位置时在此手动指定。

## 2. 终端页新交互

- **连接按钮状态化**：未连接显示「连接」，已连接显示「断开」，连接丢失/打开失败自动回到正确状态，不再出现"已连接却还写着连接"的歧义。已连接时波特率下拉灰化，悬停提示「已连接：断开后才能修改」。
- **网络串口（v2 分支预览）**：端口下拉可直接手输 pyserial URL 后点连接——`rfc2217://192.168.1.50:7000`（板端跑 ser2net，波特率由板端协商执行；NPort 等串口服务器同协议）、`socket://IP:端口`（TCP 裸透传）。板端配置样例见 `server-rk/ser2net.yaml.example`。
- **聊天式对齐**：接收（RX）行靠左，发送（TX）行靠右，类似聊天软件；行的时间先后顺序不变，窗口拉宽后右对齐自动重排。
- **悬停互转**：鼠标停在任意日志行 0.4 秒弹出提示——HEX 接收模式下把该行解码为 文本(UTF-8)/十进制/float32(小端)；文本接收模式下给出该行的 HEX。悬停条目头行等效于悬停其正文行。

## 3. 波形页：读数与导出

- **悬停读数**：在绘图区移动鼠标出现十字线与读数框——第一行是 x 坐标，随后**每条可见曲线一行「曲线名: y 值」**（与曲线同色），y 取该 x 处真实采样点。
- **「显示点数」**（原「窗口」改名）：横轴显示的帧数档位，与鼠标滚轮横轴缩放联动。
- **导出**：工具行「导出」按钮 →
  - **导出PNG**：当前时域绘图区单图渲染；
  - **导出CSV**：全量缓冲（含时间戳与全部通道）。
  - 绘图区**右键菜单**（全中文）：恢复自动缩放 / 导出PNG / 导出CSV / 显示网格。
- **XY 相位图**：工具行按钮开关。每窗口可独立选 X/Y 通道来源，量程 ±N 或自适应，窗口数 1/2/4，分格 4/5/8/10/16，点/线绘制，余晖 6 档。XY 数据同样出现在 AI 通道 `xy_snapshot` 里。

## 4. 频谱页：导出口径与清空

- **频率轴对齐**：谱图与瀑布图共用同一频率坐标（双向联动），同一频点上下垂直对齐，确认频点不再来回对轴。
- **导出PNG**：谱图 + 瀑布（勾选「瀑布」时）纵向拼图，顶部自动标注采样率 / FFT 点数 / 窗 / RBW / 通道等参数，截图即证据。
- **导出CSV**：对话框二选一：
  - **最新一帧瞬时频点**：只导当前帧的 频率/dB 两列；
  - **最近 N 秒**：导出最近 N 秒内全部帧。**N 的上限就是软件已累计采集的时长**——输入更大的值会被自动钳制到实际时长，不会导出不存在的数据。
  - 历史缓冲上限：6000 帧 或 2000 万单元格（先到为准），超限丢最旧；长时高频点采集时内存有界（约 80MB 封顶）。
- **清空**：轨迹 / 峰值保持 / 指数平均 / 瀑布 / 导出历史全部复位，采集时长清零。

## 5. STM32 页（STM32CubeProgrammer CLI）

入口：页签 **STM32**。本页通过 ST 官方 **STM32CubeProgrammer CLI** 驱动 ST-LINK，适合不切软件就能复位/烧录的联调循环。

### 5.1 前置安装

1. 从 ST 官网下载安装 **STM32CubeProgrammer**（默认路径如 `C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\` 或 `X:\ST\STM32CubeProgrammer\`）。
2. 打开 LiuScope **设置页**：CLI 路径留空即可自动探测；探测失败再手动指定 `STM32_Programmer_CLI.exe` 完整路径。
3. ST-LINK 驱动随 CubeProgrammer 安装；首次插拔建议用本页「刷新」确认枚举。

### 5.2 页面功能与按钮

| 按钮 | 行为 | 对应 CLI |
|---|---|---|
| 刷新 | 枚举 ST-LINK 探针列表（只读） | `-l` |
| 连接目标 / 断开 | 连接/断开 SWD 目标，显示 芯片型号/REV、SN、固件版本、电压 | `-c port=SWD mode=UR` |
| 软复位 / 硬复位 | 复位目标（软=系统复位，硬=NRST 板级复位） | `-rst` / `-hardRst` |
| 选择 hex/bin… / 烧录（带校验） | 烧录所选文件并自动校验：hex 走 `-d`（自带地址）；bin 走 `-w 文件 基址`（默认 0x08000000） | `-d/-w … -v` |
| 全片擦除 | 整片擦除（**毁灭性操作，慎点**） | `-e all` |
| 读保护解除 | 解除 RDP 读保护（会触发全片擦除，**毁灭性操作**） | `-rdu -y` |
| 读取 OB | 读取选项字节 | `-ob displ` |

所有命令行输出都实时回显在页面下方日志区（含 CLI 原文，便于排错）。

### 5.3 安全须知

- **烧录/全片擦除/读保护解除均不可逆**：确认所选文件与目标板正确后再操作。
- 本页只操作 **ST-LINK/SWD**，与串口页（CH340 等）互不影响，可同时使用。
- 连接状态下目标已暂停运行的场景（如低功耗），先「连接目标」再执行复位即可恢复运行。

## 6. AI 控制通道速用

GUI 启动即自动监听 `tcp://127.0.0.1:9101`（默认开启，菜单可一键复制接入信息）。一行 JSON 请求，回一行 JSON 响应。完整命令表（19 条）、follow 连续输出、无头捕获模式见 [AI_INTERFACE.md](../AI_INTERFACE.md)；随时可发 `{"cmd":"help"}` 拿同源命令表。

最快上手三条：

```jsonc
{"cmd":"status"}                         // 连接/协议/帧数/录制状态快照
{"cmd":"send","text":"INFO\r","newline":"LF"}     // 让 AI 代发一条串口命令
{"cmd":"read_lines","count":20,"filter":"ERR"}    // 按正则回读最近记录
```

三件 v1.2 重点能力：

- **数据快照**：`wave_snapshot` / `spectrum_snapshot` / `xy_snapshot` / `modbus_recent` / `stm32_status` —— AI 无需碰 UI 就能拿到波形数值、频点+dB（含主频与参数）、XY 轨迹、Modbus 事务、ST-LINK 状态。
- **连续输出**：`read_lines` 带 `follow:true` 进入持续推送（`interval` 节流、`max_lines` 上限、`filter` 过滤），发 `stop` 或直接断开退出。
- **控制与 UI 同步**：`settings_set` 改波特率/协议/显示点数/主题等，**GUI 前端同步跟随**（下拉框、按钮、页面主题真的会变），并返回改前/改后值；支持中文别名键（如 `"key":"显示点数"`）。

> 无头捕获（AI 独占串口、JSONL 输出、触发/期望/回放）见 AI_INTERFACE.md 第 2 节，适合 CI 与自动化闭环。
