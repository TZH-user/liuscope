# 插件接入指南（波形窗口插件）

> 适用于 V5/V6 波形窗口。目标：让第三方（含 AI）写的插件**不改宿主一行代码**就能挂上去，且插件自己崩了不影响宿主。

## 1. 目录与发现机制

```
plugins\
  <插件目录名>\
    plugin.ps1          ← 唯一入口文件名，宿主扫描 plugins\*\plugin.ps1
  _template\
    plugin.example.ps1  ← 模板（不会被引擎加载，只作样板）
```

- 波形窗口每次打开时扫描一次并重建插件页签（第 0 页固定为「波形」，之后每个已注册插件一页）。
- 插件目录名即逻辑名，建议小写英文，不含空格（如 `fft`、`bode`、`protocol_analyzer`）。

## 2. 最小合同

宿主在 dot-source 插件文件**之前**预置两个函数，插件必须在文件顶层调用：

```powershell
Register-WavePlugin -Name '频谱' -Description '汉宁窗 FFT 幅度谱' -OpenPanel {
    param($container)
    # 首次切入你的页签时执行一次：把控件长进 $container（页签页），不要再自己开窗
}
```

| 宿主提供 | 说明 |
|---|---|
| `Register-WavePlugin -Name -Description -OpenPanel` | 注册插件页签；`-Name` 同时是页签文字，建议 ≤4 个汉字 |
| `Get-WavePluginSnapshot -Channel <int> -Count <int>` | 取最近 N 帧该通道数值（double[]）；越界返回空数组 |
| `[WaveDsp]`（C# 静态类） | `MovingAverage(double[], int)`、`ZeroPhaseLowPass(double[], double)`、`MagnitudeSpectrum(double[], out int)` 供滤波/FFT 直接调用 |

## 3. 硬性约定（违反会在加载期被隔离）

1. **文件编码必须是 UTF-8 带 BOM**。PS5.1 对无 BOM 的 UTF-8 文件按 ANSI(GBK) 解析，中文注释/字符串会变成乱码并可能引发解析错误。
2. **不要在顶层执行耗时操作**（打开串口、启动循环）。顶层只做 `Register-WavePlugin` 与常量定义；一切资源在 `-OpenPanel` 里申请。
3. **不要读写宿主的 `$script:wave_*` 状态**（只读用 `Get-WavePluginSnapshot`）。需要自持状态时用插件自己的前缀变量，例如 `$script:fft_*`。
4. **不要注册全局事件处理器**（`$script:wave_panel.Add_Paint` 等）；要跟随重绘就用 `-OpenPanel` 里的 `Timer` 自行刷新，并在根控件 `Add_Disposed` 里 `Stop()` + `Dispose()`。
5. **异常隔离**：插件加载或运行抛错只禁用自身（页签被移除并退回波形页），写入 `logs\runtime_error.log`，不影响波形窗口其余功能。所以插件内部请自行 `try/catch`，给出可读提示。
6. **通道数可变**：每次取数都要处理「通道数变了」——不要用缓存的固定长度假设。

## 4. 版本字段（建议）

在文件头部写清宿主兼容版本，便于后续宿主升级时判断：

```powershell
$plugin_api_version = 2      # 当前宿主插件 API 版本（v2 = OpenPanel 接收页签容器）
```

宿主未提供版本校验时该字段被忽略；未来宿主可据此拒绝不兼容插件并给出提示。

## 5. 自检清单（提交插件前逐条过）

- [ ] 文件名 `plugin.ps1`，编码 UTF-8 带 BOM
- [ ] 顶层只做注册，无副作用
- [ ] `-OpenPanel` 把控件挂进传入的 `$container`，资源随根控件 `Disposed` 释放
- [ ] 所有取数走 `Get-WavePluginSnapshot`，并容忍返回空数组
- [ ] 内部错误自行捕获并提示，不向外抛
- [ ] 已验证：无数据 / 单通道 / 32 通道 / 20 万帧四种情况下不崩
- [ ] 已验证：连续开关波形窗口 3 次无残留窗口与计时器

## 6. 调测

在 `plugins\<你的插件>\` 下开发时，波形窗口每次打开都会重新加载该文件——改完直接关窗再开窗即可热加载，无需重启主程序。加载失败看 `logs\runtime_error.log`。
